Build the EXP-07 reranker weight ablation eval: does the bge-reranker score beat raw cosine by ≥3% precision@3/F1@3 on the labeled corpus? If yes, `HYBRID_WEIGHTS.rerank` stays nonzero; if no, ship `HYBRID_WEIGHTS.rerank = 0.0`. The `RERANKER_MODEL` constant lands regardless (it already did in plan 03-01). Per the D-EXP07 locked decision, the metric is precision@3/F1@3 (the corpus labels exactly 3 gold ids per query; precision@5 caps at 0.6 and is meaningless here). This is a creds-gated eval — `autonomous: false` because the live ablation run needs Cloudflare credentials the executor may not hold; the eval file is authored + unit-validated autonomously and the live run is the manual verification step.
Output: `reranker-ablation.eval.test.ts` (cloned harness, precision@3/F1@3 delta gate), an appended `docs/hybrid-rank-changelog.md` row, and — only if the ablation says so — `HYBRID_WEIGHTS.rerank = 0.0` in ai-config.

<objective>
PRE-01 is the catastrophic-gate of v0.2. ENG-25 swapped 768d → 1024d embeddings in v0.1; any block row in any workspace still stamped with `embedding_version<2` (or NULL) or the prior embedding model is silently corrupt — Vectorize will return them but they will mis-rank because the vector dimensions don't match the index. This plan installs the three-tier defense: (1) a NULL-trap SQL query helper, (2) a DO admin RPC that runs it per workspace, (3) a script that fans out across every workspace via the Cloudflare DO Namespace List API, (4) a CI job that runs the script on every push and PR and blocks merge on non-zero stale count.

The first arm of the SQL clause — `embedding_version IS NULL` — is non-negotiable. Plain `< 2` returns NULL (not TRUE) in SQL trinary logic and silently misses every NULL-stamped row, which is the most common stale state because `insertBlock` writes NULL stamps that `stampEmbedding` later fills.
</objective>

```sql
SELECT COUNT(*) AS count_stale
FROM blocks
WHERE embedding_version IS NULL
   OR embedding_version < 2
   OR embedding_model != ?
```

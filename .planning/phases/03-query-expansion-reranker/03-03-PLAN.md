## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| MCP client (JWT) → recall() → Vectorize/AI | Every fan-out Vectorize query and the reranker call run on behalf of an authenticated workspace; `workspace_id` is derived from `props` (JWT), never from caller-supplied `args`. |
| user query → reranker model | The original query is sent to bge-reranker as the `query` field; candidate content is sent as `contexts`. |

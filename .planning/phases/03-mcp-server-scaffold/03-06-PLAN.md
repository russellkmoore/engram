OAuth flow (from RESEARCH §System Architecture Diagram lines 154-238):
1. Russell adds `npx mcp-remote https://engram-mcp.<subdomain>.workers.dev/mcp` to Claude Desktop's MCP server config.
2. First call: Claude Desktop spawns mcp-remote, which opens a browser to /authorize.
3. Worker's defaultHandler reads ENGRAM_IDENTITIES KV by the OAuth `sub` (= the dynamic-registered client_id).
4. On hit → completeAuthorization with props.{workspace_id, user_id} from KV.
5. Browser callback (port 3334) writes JWT to ~/.mcp-auth/.
6. Subsequent calls use the cached JWT transparently.

Claude Desktop config (production, from RESEARCH Example 4 lines 864-876):
```json
{
  "mcpServers": {
    "engram": {
      "command": "npx",
      "args": ["mcp-remote", "https://engram-mcp.<your-subdomain>.workers.dev/mcp"]
    }
  }
}
```

Claude Desktop config (local dev, from RESEARCH Example 4 lines 880-889):
```json
{
  "mcpServers": {
    "engram-local": {
      "command": "npx",
      "args": ["mcp-remote", "http://localhost:8787/mcp"]
    }
  }
}
```

KV bootstrap (from RESEARCH Example 3 lines 834-860):
- Prereq: `wrangler kv namespace create OAUTH_KV` and `wrangler kv namespace create ENGRAM_IDENTITIES`; paste returned IDs into wrangler.jsonc (replacing the placeholder strings from Plan 05).
- Then: `wrangler secret put COOKIE_ENCRYPTION_KEY` with a random 32+ char string.
- Discover sub: first OAuth attempt fails with 403 "Unknown OAuth subject: <sub>". Copy <sub> from the error.
- Run: `npm run kv:bootstrap -- --sub <copied-sub> --workspace-id rmoore-personal --user-id rmoore`.
- Retry the OAuth flow — succeeds.

MCP Inspector smoke (from RESEARCH Pattern 7 lines 596-622):
- Terminal 1: `npm run dev --workspace=@engram/mcp-server` (wrangler dev on :8787)
- Terminal 2: `npx @modelcontextprotocol/inspector`
- In Inspector UI (opens browser): set transport to "Streamable HTTP", URL `http://localhost:8787/mcp`, click Connect.
- Click "Open Auth settings" → "Quick OAuth Flow" — completes against local /authorize (KV must have a test entry).
- Click "List tools" → MUST show all 5: remember, recall, search, forget, ingest.
- Click any tool → MUST return McpError -32601 MethodNotFound with message containing "Phase 3" and "Phase 4 (TOL-0N)".

Local dev chicken-and-egg (RESEARCH Pitfall 5 lines 687-694): the inspector requires KV entry for its dynamic client_id. Two paths:
- Path A (preferred): `wrangler dev --remote` so KV reads hit production KV that already has Russell's bootstrap entry.
- Path B (local-only): pre-cache a JWT via mcp-remote once, point inspector at the cached endpoint. Brittle, NOT documented in README.

Phase 7 Plan 04 is the first plan in Phase 7 that touches LIVE infrastructure. The trust boundaries crossed:

| Boundary | Description |
|----------|-------------|
| Local repo → Cloudflare control plane | `wrangler deploy` uploads bundled Worker code to Russell's Cloudflare account. Auth via `wrangler login` (browser-driven OAuth) or `CLOUDFLARE_API_TOKEN` env var (operator-supplied, NOT in repo). |
| Russell's Mac (Claude Desktop) → deployed Worker | Claude Desktop launches `npx mcp-remote` as a subprocess; mcp-remote OAuth-authenticates against `engram-mcp-server.<subdomain>.workers.dev/authorize` and forwards JSON-RPC tool calls over Streamable HTTP with Bearer JWT. |
| OAuth `sub` claim → ENGRAM_IDENTITIES KV | Russell pastes the observed `sub` into `kv:bootstrap` which writes `{workspace_id, user_id}` keyed on the `sub`. T-03-KV-LEAK redaction in `scripts/kv-bootstrap.mjs:121-152` prevents the identity JSON from leaking to `ps -ef`. |
| Russell's job-search agent → Engram MCP | Forward-only capture-path swap per D-05. Agent calls `remember()` through the same `/mcp` endpoint with the same Bearer JWT as direct Claude Desktop tool calls. STO-07 defense-in-depth ensures workspace isolation even if the agent's prompt template were buggy. |

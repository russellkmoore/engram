The data points land in the `engram_ai_analytics` Analytics Engine dataset (`dataset` field on the triage-worker's ANALYTICS binding in `wrangler.jsonc`; confirmed via Phase 1 scout — same dataset is shared across mcp-server and triage-worker writers). The triage-worker writes via `env.ANALYTICS.writeDataPoint(...)`; the binding's `dataset: "engram_ai_analytics"` makes this the table name in SQL API queries.

**Resolved query path (Cloudflare docs verified via Context7 2026-06-05):** The Analytics Engine **SQL API** is the documented external-tool path for querying `writeDataPoint` events:

- Endpoint: `POST https://api.cloudflare.com/client/v4/accounts/<account_id>/analytics_engine/sql`
- Auth: `Authorization: Bearer <CLOUDFLARE_API_TOKEN>` (Workers AE Read scope; same token as the existing Phase 1 nightly summary)
- Body: raw SQL string (Cloudflare uses a ClickHouse-flavored SQL surface)
- Dataset table name: `engram_ai_analytics` (binding's `dataset` field — NOT the binding name)
- Columns exposed: `timestamp`, `blob1..blob20` (string blobs in the order written), `double1..double20` (numeric doubles in the order written), `index1` (sampling index), `_sample_interval` (sampling rate)
- Quantile function: `quantileTDigest(0.99)(double1)` returns the p99 estimate (ClickHouse-style)

GraphQL was explicitly ruled out: Cloudflare docs note GraphQL "powers the Cloudflare dashboard" but the official external query path for `writeDataPoint` data is the SQL API. The Phase 1 `aiInferenceAdaptiveGroups` GraphQL node is for auto-tracked Workers AI inference data, NOT for custom Analytics Engine writes — different data path, different API surface. No node name guessing required.

Canonical query shape Plan 02-09 implements:

```sql
SELECT
  quantileTDigest(0.50)(double1) AS p50,
  quantileTDigest(0.95)(double1) AS p95,
  quantileTDigest(0.99)(double1) AS p99,
  COUNT(*) AS sample_count,
  SUM(double2) AS total_neighbors_examined
FROM engram_ai_analytics
WHERE blob1 = 'conflict-pipeline'
  AND timestamp > NOW() - INTERVAL '24' HOUR
```

CON-07 budget: p99 (latency_ms in `double1`) MUST be < 4000.

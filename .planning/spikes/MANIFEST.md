## Idea

**Workers AI extraction-quality benchmark** for Engram Phase 4 (Core Tools + Envelope). Validate that the two Cloudflare Workers AI models on the Phase 5 critical path — `@cf/meta/llama-3.1-8b-instruct` (entity extraction + summarization) and `@cf/baai/bge-base-en-v1.5` (embeddings) — produce structured outputs of sufficient quality to justify the **synthesis-only** EngramResponse envelope contract before Phase 4 freezes it on 5 production tools.

## Requirements

Locked by user choices during decomposition. Non-negotiable for the spike (and the downstream Phase 4 plan that consumes the findings).

- **Models under test (locked by ROADMAP §"Phase 5: AI Integration" SC#3 / SC#5):** `@cf/meta/llama-3.1-8b-instruct` for extraction + summarization; `@cf/baai/bge-base-en-v1.5` (768d, cosine) for embeddings. No substitutions in this spike — the spike's whole point is measuring the bound model, not picking models.
- **Samples are SYNTHETIC** (user choice during alignment): 30 samples generated by Claude spanning 3 type buckets (10 job postings, 10 meeting/decision notes, 10 research notes). **Synthetic samples carry an optimism bias** — they tend to be cleaner than real-world inputs. The D-01 decision gate is therefore tightened: **≥90% precision/recall** in synthetic conditions corresponds to ≥85% real-world (the original gate), **75–90%** corresponds to 70–85% (raw-chunks-mandatory zone), **<75%** corresponds to <70% (architecture re-open). This recalibration is documented per-spike and must survive into the Phase 4 plan's verification artifact. Real-corpus validation is deferred to a Phase 4 plan task (TOL-08 / DEP-04 territory).
- **Decision gate (synthetic-recalibrated):** ≥90% → ship envelope as-designed, `verbosity` default = `"synthesis"`. 75–90% → flip `verbosity` default to `"both"` (raw chunks always returned alongside synthesis). <75% → re-open envelope architecture (hybrid envelope vs stronger model) BEFORE Phase 4 planning resumes.
- **Output format:** structured JSON per CLAUDE.md §"What Goes Where" + ROADMAP Phase 5 SC#5. `llama-3.1-8b` extraction MUST emit JSON matching a target schema (per-bucket); free-text outputs that need post-hoc parsing don't count.
- **Spike scope is throwaway** — all code lives under `.planning/spikes/` and is NOT integrated into `packages/`. Findings flow forward via `/gsd:spike-wrap-up` into a project skill the Phase 4 planner reads.
- **`wrangler dev` uses REAL Workers AI** (no local AI emulation in workerd) — the user must have `wrangler login` configured against Russell's Cloudflare account before running spikes 001-003. Cost: ~$0.01-0.05 total across all 30 samples (extraction + embedding pricing is well under cent-per-sample).
